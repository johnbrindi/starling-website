# Archive

`door-access-proposal-v2/` holds the earlier *Starling Application Portal* proposal (Next.js + Supabase + ESP32-S3 door controllers) and its diagrams. That design was **superseded** by the paid Wi-Fi platform in this repository; ESP32 hardware is not used.

What carried over: the Starling name, the Next.js + Supabase (PostgreSQL) stack, role-based administration, audit logging, and the idea of an installable PWA.

Kept for reference only. Safe to delete once no longer needed.
