Three rules

Always connect Winbox using the MAC address (the letters/numbers like 18:FD:74:FF:17:EB), not an IP address, until Part 9. The MAC connection keeps working even if you make a mistake with IP settings.
Type values exactly as written. Small letters stay small. No extra spaces. When this guide says bridge-hotspot, type exactly that.
If you get lost, you can always start again with Part 2 (start clean). Nothing you do here can damage the router.

Part 1

Winbox basics

Five things you will use in every step.

1
Connecting Open Winbox → Neighbors tab → Refresh → click the line that shows hAP lite → make sure the MAC address appears in “Connect To” → Login admin, Password: empty (or the password you set in Part 3) → Connect.
2
The menu on the left Everything is in the left menu: Interfaces, Wireless, Bridge, IP (has a sub-menu: Addresses, DHCP Client, DNS, Hotspot, Firewall…), System (sub-menu: Password, Identity, Clock, Packages, Reset Configuration…), Files, New Terminal. In this guide, “IP → DNS” means: click IP, then DNS in the sub-menu.
3
Adding and editing In most windows, the blue + (or New) button adds an item. Double-click a line to edit it. In an edit window, Apply saves and keeps it open, OK saves and closes.
4
The terminal (for copy-paste commands) New Terminal opens a black window. You can paste a command there (right-click → Paste, or Ctrl+V) and press Enter. Every step in this guide shows both ways: the clicks, and the command. Use one or the other for a step, not both. If you are unsure, use the clicks.
5
Safe Mode (your undo button) The Safe Mode button (top right in Winbox) protects you: while it is on, if Winbox loses the connection, the router automatically undoes your last changes. Turn it on before risky steps (this guide tells you when), and turn it off again when you are happy with the result so the changes are kept.
Your Winbox may look slightly different (newer Winbox 4 has a darker style and some buttons are named “New” instead of “+”). The menu names are the same.
Part 2

Start clean

Your router is almost empty already (it showed a bridge1). We erase everything so it is in a known state.

1
Reset with no configuration System → Reset Configuration → tick No Default Configuration → leave the other boxes unticked → Reset Configuration → confirm Yes. 
/system reset-configuration no-defaults=yes skip-backup=yes
(In the terminal, type y and Enter when it asks “Dangerous! Reset anyway?”)
2
Wait and reconnect Winbox disconnects. Wait about 1 minute (the router reboots). Then Winbox → Neighbors → Refresh → click the MAC address → login admin, empty password → Connect. If it asks about the default configuration, click Remove Configuration (or OK).
Bridge is empty, IP → Addresses is empty. That is correct.
The router does not appear in Neighbors: unplug the yellow cable from the PC and plug it back in, wait 20 seconds, Refresh again. Try another port (2 or 3) on the router.
Part 3

Password, name and clock

1
Set the admin password System → Password → Old Password: empty → New Password and Confirm: a strong password (write it in Part 0) → Change. 
/password old-password="" new-password="YourStrongPassword" confirm-new-password="YourStrongPassword"
2
Give the router a name System → Identity → starling-hotspot → OK. 
/system identity set name=starling-hotspot
3
Time zone and automatic clock System → Clock → Time Zone Name: Africa/Douala → OK. Then System → SNTP Client → tick Enabled → Primary NTP Server 162.159.200.1, Secondary 162.159.200.123 → OK. 
/system clock set time-zone-name=Africa/Douala
/system ntp client set enabled=yes primary-ntp=162.159.200.1 secondary-ntp=162.159.200.123
The clock matters: customers' time is counted with it. It will show the right time once the internet works (Part 4).
From now on, log in with admin and your new password.
Part 4

Internet from Starlink (port 1)

The router asks the Starlink router for an address on port 1, exactly like a phone does.

1
Check Starlink The Starlink app says Online, and the blue cable goes from a Starlink router Ethernet/LAN port to port 1 of the MikroTik.
2
Add a DHCP client on port 1 IP → DHCP Client → + → Interface: ether1 → Use Peer DNS: unticked → Add Default Route: yes → OK. 
/ip dhcp-client add interface=ether1 use-peer-dns=no add-default-route=yes disabled=no comment="Internet from Starlink"
In the DHCP Client list, the Status becomes bound and an IP address appears (for example 192.168.1.23/24, or 100.x.x.x if Starlink is in bypass mode).
Status stays “searching…”: check the blue cable is in port 1 and in the Starlink router; restart the Starlink router; wait 1 minute. If Starlink uses the Ethernet Adapter, check it is connected.
3
Set the DNS servers IP → DNS → Servers: 1.1.1.1 and (click the small arrow to add a line) 8.8.8.8 → tick Allow Remote Requests → OK. 
/ip dns set servers=1.1.1.1,8.8.8.8 allow-remote-requests=yes
4
Test the internet New Terminal and type: 
/ping google.com count=4
Four lines with a time like time=40ms and “received=4”.
“could not resolve”: redo step 3. “timeout”: the DHCP client is not bound; redo step 2.
5
Check the clock System → Clock: the date and time are now correct (Douala time). If not, wait 2 minutes and look again.
Part 5

Update the router

Always update before configuring the hotspot, so an update does not change your settings later. Your router has 6.48.6; we move to the latest 6.49 “long-term” version.

1
Download and install System → Packages → Check For Updates → Channel: long-term → wait until it shows the Latest Version (6.49.something) → Download&Install. 
/system package update set channel=long-term
/system package update check-for-updates
/system package update install
The router downloads, then reboots by itself (Winbox disconnects). Wait 2–3 minutes, reconnect by MAC. System → Packages shows the new version.
2
Update the RouterBOARD firmware System → RouterBOARD → if “Current Firmware” and “Upgrade Firmware” are different, click Upgrade → OK. Then System → Reboot → Yes. Reconnect after 1 minute. 
/system routerboard upgrade
/system reboot
Do not unplug the power while it is updating. If the update fails or does not show 6.49, that is fine: continue with 6.48.6. Everything in this guide works on both.
Stay on version 6 (long-term). Do not choose the “stable/7” channel: the hAP lite has very little storage and this guide is written for version 6.
Part 6

Customer network (the bridge)

A “bridge” joins ports 2, 3, 4 and the Wi-Fi into one customer network. Port 1 (internet) must NOT be in it.

1
Create the bridge Bridge → Bridge tab → + → Name: bridge-hotspot → OK. 
/interface bridge add name=bridge-hotspot comment="Customers"
2
Put ports 2, 3, 4 and the Wi-Fi in it Bridge → Ports tab → + → Interface ether2, Bridge bridge-hotspot → OK. Repeat for ether3, ether4 and wlan1. 
/interface bridge port add bridge=bridge-hotspot interface=ether2
/interface bridge port add bridge=bridge-hotspot interface=ether3
/interface bridge port add bridge=bridge-hotspot interface=ether4
/interface bridge port add bridge=bridge-hotspot interface=wlan1
The Ports tab lists ether2, ether3, ether4, wlan1, all with bridge bridge-hotspot. ether1 is not there.
Winbox may disconnect for a second because your PC (port 4) just moved into the bridge. Reconnect by MAC. This is normal.
3
Give the customer network its address IP → Addresses → + → Address 10.5.50.1/24 → Interface bridge-hotspot → OK. 
/ip address add address=10.5.50.1/24 interface=bridge-hotspot comment="Customer gateway"
IP → Addresses shows 10.5.50.1/24 on bridge-hotspot (and the Starlink address on ether1, marked D).
10.5.50.1 is your router's address for customers. Customers will get addresses 10.5.50.10 to 10.5.50.250. The Tenda will later get 10.5.50.2.
Part 7

The router's own Wi-Fi (for testing now)

The hAP lite has a small indoor Wi-Fi. We turn it on so you can test everything before mounting the Tenda. You can keep it on afterwards as a second, indoor access point.

1
Make the Wi-Fi open (no password) The hotspot login page is the lock, so the Wi-Fi itself has no password (like airports and cafés). Wireless → Security Profiles tab → double-click default → Mode: none → OK. 
/interface wireless security-profiles set [find default=yes] mode=none
2
Set the Wi-Fi name and turn it on Wireless → WiFi Interfaces tab → double-click wlan1 → Wireless tab: Mode ap bridge, Band 2GHz-B/G/N, Channel Width 20MHz, Frequency auto, SSID Starling Wi-Fi, Security Profile default → OK. Then select wlan1 and click the blue tick ✓ Enable. 
/interface wireless set wlan1 mode=ap-bridge band=2ghz-b/g/n channel-width=20mhz frequency=auto ssid="Starling Wi-Fi" security-profile=default wireless-protocol=802.11 disabled=no
On your phone, a Wi-Fi called Starling Wi-Fi appears, without a lock icon. Do not connect yet: there is no hotspot until Part 8, so the phone would not get an address.

/interface bridge port remove [find interface=wlan1]
/interface bridge port add bridge=bridge-hotspot interface=wlan1
/ip dhcp-server network remove [find]

Part 9

Let your own PC and phone skip the login

Your PC on port 4 is now on the customer network, so its browser would also need to log in. You can let your own devices through without a ticket.

1
Find your PC's MAC address IP → DHCP Server → Leases tab. Your PC is the line with your PC's name (Host Name). Note its MAC Address. (Also your phone's, from the test in Part 8.)
2
Add a bypass IP → Hotspot → IP Bindings tab → + → MAC Address: your PC's MAC → Type: bypassed → Comment: Owner PC → OK. Repeat for your own phone. 
/ip hotspot ip-binding add mac-address=AA:BB:CC:DD:EE:FF type=bypassed comment="Owner PC"
(Replace AA:BB:CC:DD:EE:FF with the real MAC.)
On your PC, any website opens without the login page.
Only add your own devices. Every bypassed device uses internet without paying and without speed limits.

Hotspot settings

The settings the video recommends: one address per phone, and the login methods.

1
One address per phone IP → Hotspot → Servers → double-click your server (server1 or hotspot1) → Addresses Per MAC: 1 → OK. 
/ip hotspot set [find] addresses-per-mac=1
2
Login methods IP → Hotspot → Server Profiles tab → double-click hsprof1 → Login tab → tick HTTP CHAP, HTTP PAP, MAC Cookie, Cookie (untick the others) → OK. (How long the MAC cookie lasts is set in the packages, Part 11.) 
/ip hotspot profile set hsprof1 login-by=http-chap,http-pap,mac-cookie,cookie
SettingWhy

HTTP PAPNeeded by your Starling login page (Part 12) and later the website's Connect button.
MAC CookieA phone that already logged in is let back in automatically after it reconnects, without typing again (until its time ends).

Part 12

Your Juthelink pages and automatic logins

Two things go on the router: the three Juthelink pages (what customers see) and one small script that collects the logins customers buy on the website, every 10 seconds. Together they use about 15 KB.

Where are the files? In Juthelink-Router-Kit.zip: the folder hotspot (login.html, alogin.html, status.html) and the file juthelink-sync.rsc. They are already made for your website starling-website-lilac.vercel.app. No editing needed.
Keep juthelink-sync.rsc private. It contains the router's secret key for the website. Do not send it on WhatsApp or post it anywhere. If it leaks, ask for a new key and a new file.
1
Unzip the kit on your PC Right-click the zip → Extract. You get the PDF, juthelink-sync.rsc, starling-profiles.rsc, ticket-maker.html and the hotspot folder.
2
Upload the three pages into the hotspot folder Winbox → Files → drag login.html, alogin.html and status.html from the kit's hotspot folder onto the hotspot folder (or open the folder and click Upload). Replace the old files when asked.
hotspot/login.html, hotspot/alogin.html, hotspot/status.html with today's date, inside the hotspot folder.
They appear at the top level: drag them onto the folder name, or remove and upload again. Close and reopen Files if the list does not refresh.
3
Remove the logout page Delete hotspot/logout.html (customers must not log out and pass their login to someone else). Leave every other file in the hotspot folder: the router uses some of them itself. To get MikroTik's original pages back at any time: IP → Hotspot → Server Profiles → Reset HTML.
4
Install the automatic-login script Drag juthelink-sync.rsc into the Files window at the top level (not into the hotspot folder). Then open New Terminal and type: 
/import file-name=juthelink-sync.rsc
Juthelink sync installed: the router now checks the website every 10 seconds. In System → Scheduler there is juthelink-sync with interval 00:00:10, and in IP → Hotspot → Walled Garden IP List there is starling-website-lilac.vercel.app (customers can open the website before they log in).
“failure” or nothing happens: the file must be at the top level in Files and named exactly juthelink-sync.rsc. Running the import again is safe.
5
Make sure both login methods are on In the terminal: 
/ip hotspot profile set [find] login-by=http-chap,http-pap,cookie,mac-cookie
(The Juthelink page works with either; having both on avoids surprises.)
6
Check the router reaches the website Wait 30 seconds, then Log. There must be no red line “juthelink-sync: website not reachable”. If there is, check the router has internet (/ping google.com count=3) and the clock is right (Part 3).
Part 13

How selling works (automatic, with Campay)

Customers pay with MTN MoMo or Orange Money through Campay. The website checks the payment with Campay itself, creates the login, and the router picks it up within about 10 seconds. The phone is then logged in automatically. You do nothing.

#What the customer does / sees
1Joins the Wi-Fi. The Juthelink page opens. Taps a plan: it gets a ✓ and “Selected: …”.
2Taps Pay … FCFA and connect. The Juthelink website opens (allowed before login).
3First time: creates a free account (name, phone, password). Next time: signs in.
4Taps Pay. A MoMo / Orange Money prompt appears on their phone; they enter their PIN. (No prompt? Dial *126# for MTN or #150*50# for Orange to approve.)
5“Payment confirmed”. A few seconds later the phone goes back to the Juthelink page, the username and password are filled in automatically and it connects by itself.
6“You are connected”, then the Time left page counting down. When the time is up the router disconnects them and deletes the login.
A payment counts only when Campay confirms it to the website, for the exact amount. A customer cannot get internet by faking a page or a screenshot. A declined or cancelled payment gives nothing; the customer can try again.

Where do the logins come from?

The website makes a random username (6 letters/numbers, e.g. k7m4qx) and a 6-digit password for each purchase. The router adds it with the right package and puts the customer's phone number in the comment. At the first login the router adds the start and end time to that comment. You can see every login in IP → Hotspot → Users.

“I lost my login” / changed phone

On the Juthelink page: Lost your login? → My account, sign in with their phone number and password: the login is shown again with a Connect button. Forgot their password too? They tap “Forgot password” and use their Wi-Fi username or a code you give them from the admin site.

A customer who already logged in on a phone is usually let back in automatically (MAC cookie) until their time ends.

Where is the money?

In your Campay account (campay.net → your app starling → Money balance / Transactions). Every Juthelink payment has a reference like SW-20261024-XXXXXXXX that you also see in the admin site under Payments. Withdraw from Campay to your MoMo as usual.

Family members (free access)

For family members who contributed to buying the Starlink: open ticket-maker.html → Plan: Family member (free) → type their name (and phone) → Make ticket → paste the command into Winbox New Terminal → send them the message. Example:

/ip hotspot user add name=marie766 password=261043 profile=family comment="FAMILY: Marie Ngono, 677123456"
  • Free, never expires, up to 2 of their own devices, faster speed (5/10 Mbit/s).
  • In IP → Hotspot → Users family logins have profile family and a comment starting with FAMILY:. Find → FAMILY lists them all.
  • If a family login is shared with the public, change its password or click ✗ Disable.

Cash customers and printed tickets

Someone pays you in cash? Use ticket-maker.html (works offline on your PC): choose the plan, Make ticket, paste the command into Winbox, give them the username and password. For tickets to sell later, leave the phone empty and choose e.g. 20 → Print. Each ticket's time starts at its first login.

Part 14

Tenda outdoor access point

The Tenda must only broadcast the Wi-Fi (“AP mode”). The MikroTik does everything else. If the Tenda acts as a router, all customers look like one phone and the hotspot cannot tell them apart.

14.1 Configure the Tenda on your desk first

1
Wire it to your PC (not to the MikroTik yet) Tenda cable → PoE port of the Tenda injector. Injector LAN port → your PC. Injector power → socket. Wait 1–2 minutes for the Tenda to start.
2
Reset the Tenda With power on, press and hold its reset button (or the button on the unit) for about 8 seconds, until the lights flash. Wait 1 minute.
3
Give your PC an address in the Tenda's range Look at the label on the Tenda for the default address (often 192.168.2.1, user admin, password admin). On Windows: Settings → Network → Ethernet → IP assignment → Edit → Manual, IPv4 on, IP address 192.168.2.100, Subnet mask 255.255.255.0, Gateway empty → Save.
4
Open the Tenda settings Browser → http://192.168.2.1 (or the address on the label) → log in. Set a new admin password if asked (write it in Part 0).
5
Choose AP mode Find Working Mode / Operation Mode / Quick Setup → choose AP (Access Point). Not Router, WISP, Client+AP or Repeater.
6
Wi-Fi name and security Wireless / Wi-Fi settings: SSID Starling Wi-Fi (exactly the same as the MikroTik), Security None / Open, Country Cameroon (if listed), Channel 1, 6 or 11 (choose a different one from the hAP lite if you keep both), Channel width 20 MHz. If there is Client Isolation / AP Isolation, turn it on.
7
LAN address and DHCP LAN / Network settings: IP Address 10.5.50.2, Subnet mask 255.255.255.0, Gateway 10.5.50.1, DNS 10.5.50.1. DHCP server: OFF (if the option exists). Save. The Tenda reboots; your browser loses it. That is expected.
8
Put your PC back to automatic Windows: Ethernet → IP assignment → Edit → Automatic (DHCP) → Save.

14.2 Connect the Tenda to the MikroTik

MikroTik port 2→ cable →Injector LAN Injector PoE→ long outdoor cable →Tenda

The injector also plugs into the power socket. Never plug the PoE port into the MikroTik or your PC.

1
Plug in Short cable from MikroTik port 2 to the injector's LAN port. Keep the PoE port going to the Tenda.
2
Check the Tenda is visible to the MikroTik Winbox → New Terminal: 
/ping 10.5.50.2 count=4
Four replies. From your PC (bypassed), http://10.5.50.2 opens the Tenda settings.
No reply: check the cable is in port 2 and the injector's LAN port; redo 14.1 step 7 (address 10.5.50.2, gateway 10.5.50.1).
3
Test through the Tenda Stand near the Tenda (or turn off the hAP lite Wi-Fi for the test: Wireless → select wlan1 → ✗ Disable). Phone → Starling Wi-Fi → open http://neverssl.com.
The blue Starling login page. In Winbox, IP → DHCP Server → Leases shows your phone's own MAC address and a 10.5.50.x address.
The phone gets a 192.168.x.x address, or several phones show the same MAC in IP → Hotspot → Hosts: the Tenda is still in router mode or its DHCP is on. Redo 14.1 steps 5 and 7.

14.3 Mounting outdoors

  • Mount it 3–6 m high on a pole or wall, facing where customers sit, antennas pointing up.
  • Leave a “drip loop” (a U-shaped bend) in the cable below the Tenda so rain runs off, and close the cable cover tightly.
  • Keep the injector indoors and dry.
  • If you keep the hAP lite's own Wi-Fi on (indoors), use a different channel from the Tenda (e.g. 1 and 11). Same name is fine: phones pick the strongest.

Problems and fixes

ProblemFix
Winbox cannot find the routerUse the MAC address. Replug the yellow cable. Try another port. Last resort: hardware reset (unplug power, hold reset, plug power, keep holding about 5 s until the light flashes, release), then start again at Part 2.
DHCP Client on ether1 not “bound”Blue cable in port 1? Starlink app Online? Restart the Starlink router.
Customers get internet without logging inFastTrack rule active (Part 8 step 2), or the device is bypassed (Part 9), or the hotspot server hotspot1 is disabled.
Grey MikroTik page instead of the blue oneFiles not inside the hotspot folder or wrong name (Part 12).
No login page pops upOpen http://neverssl.com or http://login.starling. HTTPS sites (Google, Facebook) cannot show the login page; that is normal.
“invalid username or password”Extra space or capital letter. Check the user in IP → Hotspot → Users. The user may have expired (deleted).
“no more sessions are allowed for user”Another phone is using this ticket (or the same phone with a new random MAC). Remove it from Active, and ask the customer to turn off private Wi-Fi address.
Customer asked to log in again and againPrivate / random Wi-Fi address is on. See Part 16.
Phones get 192.168.x.x addressesTenda DHCP is on or Tenda is in router mode (Part 14.1 steps 5 and 7).
All phones show the same MAC in IP → Hotspot → HostsTenda is in router mode. Put it in AP mode.
Time ended too early or too lateClock wrong: System → Clock and System → SNTP Client (Part 3 step 3). Check internet works.
“Pay … and connect” opens a blank / error pageThe website is not in the walled garden: import juthelink-sync.rsc again (Part 12 step 4). Check the router has internet and DNS (/ping starling-website-lilac.vercel.app).
Paid, “Payment confirmed”, but not connected after 1 minuteLog shows “website not reachable”: router internet or clock problem (Part 3, Part 4). Or the scheduler juthelink-sync is disabled. The customer can tap My account → Connect once it is fixed; the login is kept.
Log: “juthelink-sync: could not add … (profile …)”The package profiles are missing: import starling-profiles.rsc again (Part 11).
“We could not start the payment”The number is not a MoMo / Orange Money number, or Campay is down. Ask the customer to try again or use another number.
Profiles import failsThe file must be at the top level in Files. Run the import again.
Everything is slowCheck Starlink speed in the Starlink app. Lower the per-customer speed in the profiles. Check router CPU.
Appendix A

All commands in one place

Exactly what the clicks above do, for the terminal. Run them in order, one block at a time, after Part 2 (start clean). Replace the values in CAPITALS first.

# Part 3 - password, name, clock
/password old-password="" new-password="YOUR-PASSWORD" confirm-new-password="YOUR-PASSWORD"
/system identity set name=starling-hotspot
/system clock set time-zone-name=Africa/Douala
/system ntp client set enabled=yes primary-ntp=162.159.200.1 secondary-ntp=162.159.200.123

# Part 4 - internet from Starlink on port 1
/ip dhcp-client add interface=ether1 use-peer-dns=no add-default-route=yes disabled=no comment="Internet from Starlink"
/ip dns set servers=1.1.1.1,8.8.8.8 allow-remote-requests=yes
/ping google.com count=4

# Part 6 - customer bridge
/interface bridge add name=bridge-hotspot comment="Customers"
/interface bridge port add bridge=bridge-hotspot interface=ether2
/interface bridge port add bridge=bridge-hotspot interface=ether3
/interface bridge port add bridge=bridge-hotspot interface=ether4
/interface bridge port add bridge=bridge-hotspot interface=wlan1
/ip address add address=10.5.50.1/24 interface=bridge-hotspot comment="Customer gateway"

# Part 7 - the hAP lite's own open Wi-Fi
/interface wireless security-profiles set [find default=yes] mode=none
/interface wireless set wlan1 mode=ap-bridge band=2ghz-b/g/n channel-width=20mhz frequency=auto ssid="Starling Wi-Fi" security-profile=default wireless-protocol=802.11 disabled=no

# Part 8 - hotspot (what the Hotspot Setup wizard creates)
/ip pool add name=hs-pool ranges=10.5.50.10-10.5.50.250
/ip dhcp-server add name=dhcp-hotspot interface=bridge-hotspot address-pool=hs-pool lease-time=1h disabled=no
/ip dhcp-server network add address=10.5.50.0/24 gateway=10.5.50.1 dns-server=10.5.50.1
/ip hotspot profile add name=hsprof1 hotspot-address=10.5.50.1 dns-name=login.starling html-directory=hotspot smtp-server=0.0.0.0
/ip hotspot add name=hotspot1 interface=bridge-hotspot address-pool=hs-pool profile=hsprof1 disabled=no
/ip hotspot user add name=admin password="YOUR-TEST-PASSWORD"
/ip firewall nat add chain=srcnat src-address=10.5.50.0/24 action=masquerade comment="masquerade hotspot network"
/ip firewall filter disable [find action=fasttrack-connection]

# Part 9 - your own devices skip the login
/ip hotspot ip-binding add mac-address=YOUR:PC:MAC:AA:BB:CC type=bypassed comment="Owner PC"

# Part 10 - hotspot settings
/ip hotspot set [find] addresses-per-mac=1
/ip hotspot profile set hsprof1 login-by=http-chap,http-pap,mac-cookie,cookie

# Part 11 - packages (upload starling-profiles.rsc to Files first)
/import file-name=starling-profiles.rsc

# Part 13 - a customer
/ip hotspot user add name=frank482 password=739215 profile=24hours

# Backup
/export file=starling-working
